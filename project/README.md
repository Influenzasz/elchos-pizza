# Elcho's Pizza — Автоматизированная система управления пиццерией (Enterprise Suite)

Комплексное промышленное решение для автоматизации ресторанного бизнеса, сетей пиццерий и служб доставки. Система объединяет в едином пространстве клиентский онлайн-сервис, рабочие места персонала, кухонные терминалы, экраны выдачи заказов и модуль складского учета.

---

## 1. Архитектура и технологии

- **Серверный стек:** C# (.NET Framework 4.0 / 4.8 / Core-ready) с собственным многопоточным HTTP/1.1 веб-сервером и диспетчером REST API.
- **База данных:** Встроенная реляционная СУБД SQLite (`pizza.db`) с режимом Write-Ahead Logging (WAL) через системную библиотеку Windows `winsqlite3.dll`. Полная автономность и работа без сторонних служб СУБД.
- **Шина реального времени:** Server-Sent Events (SSE) / EventBus — мгновенная сквозная синхронизация статусов заказов между сайтом, кассой, кухней, залом и курьерами без задержек и перезагрузок страниц.
- **Десктопные интерфейсы:** Автономные `.exe` лаунчеры, запускающие рабочие места в изолированном режиме нативных приложений Windows (`--app`) без рамок браузера, вкладок и адресных строк.
- **Фронтенд:** Адаптивное Single Page Application (HTML5, CSS3 Grid/Flexbox, JavaScript ES6+, Web Audio API).

## 3. Рабочие модули системы

| Исполняемый файл | Рабочее место | Маршрут | Описание |
| :--- | :--- | :--- | :--- |
| **`Запуск_Пиццерии.exe`** | Онлайн-витрина | `/` | Клиентский сайт с каталогом, конструктором пиццы (размеры 25/30/35 см, бортики, добавки), корзиной, промокодами и трекером готовности. |
| **`Касса_POS.exe`** | Кассир (POS) | `/pos` | Сенсорная сетка быстрой продажи, прием оплаты (наличные, карта, QR), мгновенная отправка в цех кухни, печать фискального чека ООО «Элчос Пицца». |
| **`Кухня_KDS.exe`** | Кухня (KDS) | `/kitchen` | Интерактивный экран поваров: новые заказы, смена этапов («В работу», «В печи», «Готово»), звуковое оповещение о новых чеках, таймеры. |
| **`Табло_Очереди.exe`** | Зал пиццерии | `/board` | Электронное табло для гостей: разделы «Готовятся» и «Готовы к выдаче», звуковой гонг при готовности, динамическая строка новостей. |
| **`Киоск_Заказа.exe`** | Терминал гостей | `/kiosk` | Сенсорный киоск самообслуживания: режим ожидания (Attract Screen), выбор позиций, оплата и печать номера заказа. |
| **`Курьер_Доставка.exe`**| Курьер (PWA) | `/courier` | Мобильный экран доставки со списком адресов, телефоном клиента, суммами и кнопкой подтверждения вручения. |
| **`Администратор.exe`** | Управление (ERP)| `/admin` | Складской учет (WMS) с автоматическим списанием сырья, статистика выручки, управление меню и ценами, журнал аудита действий. |
| **`Сервер.exe`** | Ядро системы | `:5000` | Консольный сервер обработки запросов, WebSocket/SSE шины и целостности данных. |
| **`Тест_Системы.exe`** | Сквозной валидатор | Консоль | Автоматический прогон 30 сквозных интеграционных сценариев (авторизация, каталог с оригинальными фото высокого разрешения, заказы, KDS, WMS, POS, чеки, промокоды). |
