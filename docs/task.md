## 🔍 Детальный чеклист по фазам разработки

### Фаза 0: Discovery & ТЗ
- [x] Формирование User Stories для клиентов, кассиров, поваров, курьеров и директоров.
- [x] Проектирование реляционной схемы данных (ERD) в третьей нормальной форме (3NF).
- [x] Фиксация контрактов REST API (33 эндпоинта) до интеграции интерфейсов.
- [x] Определение модульной структуры репозитория (`project/src/`, `project/wwwroot/`, `приложения/`).

### Фаза 1: Инфраструктура и скелет
- [x] Реализация концепции On-Premise Zero-Dependency (работа без сторонних СУБД и серверов).
- [x] Инициализация C# решения (.NET Framework 4.0/4.8 / Core-ready) с прямым P/Invoke к `winsqlite3.dll`.
- [x] Создание единого файла переменных окружения и конфигурации (`appsettings.json`, `.env.example`).
- [x] Настройка пакетного запуска в 1 клик (`Запуск_Пиццерии.bat`).

### Фаза 2: База данных и модели
- [x] Реализация высокопроизводительного режима Write-Ahead Logging (WAL) для многопоточного доступа.
- [x] Проектирование таблиц номенклатуры (Categories, Products, PizzaSizes, DoughTypes, Toppings).
- [x] Создание структуры складского учета WMS (Inventory, ProductRecipes с нормами расхода в граммах).
- [x] Проектирование таблиц фискальных смен и чеков (CashShifts, FiscalReceipts) по 54-ФЗ.
- [x] Автоматический сидер первичных данных (`DbInitializer.cs`) с 44 позициями меню и фото.

### Фаза 3: Backend API и бизнес-логика
- [x] Многопоточный сокетный веб-сервер HTTP/1.1 (`HttpServer.cs`) с неблокирующей обработкой сокетов.
- [x] Диспетчеризация REST API маршрутов (`ApiHandler.cs`) с разделением на транспортный и доменный слои.
- [x] Подсистема реального времени (EventBus) на базе Server-Sent Events (SSE) без холостого polling.
- [x] Автоматическое списание сырья со склада при подтверждении заказа с учетом размеров (25/30/35 см).
- [x] Ролевая модель доступа RBAC (`admin`, `cashier`, `chef`, `courier`, `client`) с отсечением HTTP 403 Forbidden.

### Фаза 4: Frontend и клиентский UX (WOW-Aesthetics)
- [x] Клиентская витрина онлайн-заказа (`index.html`) с интерактивным конструктором пиццы и онлайн-трекером.
- [x] Сенсорный терминал кассира (`pos.html`) с быстрой сеткой продажи, приемом оплат и чеками 54-ФЗ.
- [x] Кухонный экран повара (`kitchen.html`) со стадиями («В работу», «В печи», «Готово») и техкартами.
- [x] Электронное табло очереди зала (`board.html`) со звуковым гонгом вызова через Web Audio API.
- [x] Сенсорный киоск самообслуживания (`kiosk.html`) с режимом ожидания Attract Screen.
- [x] Мобильный интерфейс курьера (`courier.html`) с маршрутами и подтверждением вручения.
- [x] Административная ERP-панель (`admin.html`) со складом, стоп-листами, выручкой и журналом аудита.

- [x] Нативные десктопные лаунчеры в папке `приложения/` (`--app` kiosk-mode).
