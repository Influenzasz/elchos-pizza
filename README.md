# 🍕 Elcho's Pizza — Автоматизированная система управления пиццерией (Enterprise Suite)

Комплексное промышленное On-Premise решение для автоматизации ресторанного бизнеса, сетей пиццерий и служб экспресс-доставки готовой кулинарной продукции.

Система объединяет в режиме реального времени клиентский онлайн-сервис, сенсорные рабочие места кассиров, кухонные дисплеи поваров (KDS), табло выдачи заказов в зале, сенсорные киоски гостей, мобильные экраны курьеров и контур складского учета сырья (WMS) с соблюдением требований 54-ФЗ и 152-ФЗ.

---

## 🚀 Быстрый старт: развертывание за 3 минуты

Система спроектирована по стандарту **Zero-Dependency** и не требует установки сторонних СУБД, веб-серверов или тяжелых фреймворков.

1. **Запуск локального сервера:**
   Кликните дважды по файлу **`Запуск_Сервера_Локально.exe`** в корне папки.
   * Сервер мгновенно запустится по адресу `http://localhost:5000` и откроется сайт в браузере.
2. **Запуск онлайн-сервера (Облако Render):**
   Кликните дважды по файлу **`Запуск_Сервера_Онлайн.exe`** в корне папки.
   * Откроется облачный сервер пиццерии. Адрес можно настроить в `online_url.txt`.
3. **Проверка работоспособности (Автотесты):**
   Запустите **`project\Тест_Системы.exe`** — программа за 1.5 секунды выполнит 40 сквозных интеграционных тестов.
4. **Открытие рабочих мест персонала:**
   Запустите исполняемые файлы из папки `приложения/`:
   * Кассир: `приложения\Касса_POS.exe` (маршрут `/pos`)
   * Повар: `приложения\Кухня_KDS.exe` (маршрут `/kitchen`)
   * Табло зала: `приложения\Табло_Очереди.exe` (маршрут `/board`)
   * Терминал гостей: `приложения\Киоск_Заказа.exe` (маршрут `/kiosk`)
   * Директор / Склад: `приложения\Администратор.exe` (маршрут `/admin`)
   * Курьер: `http://localhost:5000/courier`

## 🛠 1. Архитектура и технологии

- **Серверный стек:** C# (.NET Framework 4.0 / 4.8 / Core-ready) с собственным многопоточным HTTP/1.1 веб-сервером на сокетах и REST API диспетчером (`Server.exe`).
- **База данных:** Встроенная реляционная СУБД SQLite (`project/pizza.db`), работающая через системный драйвер Windows `winsqlite3.dll` (P/Invoke) в высокопроизводительном режиме Write-Ahead Logging (WAL).
- **Шина реального времени:** Server-Sent Events (SSE) / EventBus — мгновенная сквозная синхронизация статусов заказов между сайтом, кассой, кухней, залом и курьерами без холостого опроса сервера (no-polling).
- **Клиентские интерфейсы:** Адаптивное Single Page Application (HTML5, CSS3 Grid/Flexbox, ES6+ JavaScript, Web Audio API).
- **Десктопные лаунчеры:** C# приложения в папке `приложения/`, запускающие интерфейсы в нативном Kiosk-режиме (`--app`) без элементов управления браузера.

```text

├── приложения/                  # Десктопные интерфейсы рабочих станций
│   ├── Касса_POS.exe            # Сенсорный POS-терминал кассира
│   ├── Кухня_KDS.exe            # Кухонный дисплей повара (KDS)

│   ├── Администратор.exe        # Панель управления, меню и WMS-склад
│   └── Курьер_Доставка.exe      # Мобильный интерфейс курьерской доставки
│
├── docs/                        # Техническая документация проекта
│   ├── API_DOCUMENTATION.md     # Спецификация REST API эндпоинтов
│   ├── DEPLOY_AND_BACKUP.md     # Развертывание в локальной сети и бэкапы
│   ├── DEPLOY_RENDER_RAILWAY.md # Облачный хостинг на Render и Railway
│   └── USER_GUIDE.md            # Руководство пользователя
│
├── scripts/                     # Вспомогательные скрипты обслуживания
│   ├── Отправить_В_GitHub.bat   # Быстрая синхронизация с GitHub
│   └── Восстановить_Навыки.bat  # Восстановление настроек
│

│   ├── wwwroot/                 # Веб-интерфейсы (HTML5/CSS3/JS)
│   ├── pizza.db                 # Реляционная СУБД SQLite
│   ├── Server.exe               # Сервер Kestrel-lite

├── Диплом_Пиццерия/             # Академические материалы по ГОСТ
```
